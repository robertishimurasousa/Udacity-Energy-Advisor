# Security Policy

## Supported Versions

EcoHome Energy Advisor is maintained on the default branch.

| Version | Security updates |
| --- | --- |
| Current `main` | Supported |
| Earlier snapshots or forks | Outside the maintenance scope |

## Reporting a Vulnerability

Open the repository's [Security Advisories page](https://github.com/robertishimurasousa/Udacity-Energy-Advisor/security/advisories) and select **Report a vulnerability** to contact the maintainer privately. Keep vulnerability details in the private report while it is being reviewed.

Include the affected commit, Python and dependency versions, the affected feature, the observed behavior, and the potential impact. Use synthetic data and redact API keys, personal information, and secrets from logs and attachments.

The maintainer will review reports as availability permits and post updates in the private GitHub thread when the status changes or more information is needed. If the report is accepted, the maintainer can coordinate a fix and disclosure in the advisory. If the report is declined, the thread will record the reason when possible.
